Description
-----------

  This is a small game which can help you to kill free time.
  The purpose of the game is to score points more than the
"king" has. Your score will increase when you build up a
horizontal, vertical or diagonal line consisting of five
or more one-color balls. You can make these lines by moving
balls across vacant squares.
  Programs saves hiscores into the file lines.res if it present,
otherwise it saves hiscores into the file winlines.res.
  If you're have any questions about this program contact to
Ivan Golubev at m53group@piter.net.
